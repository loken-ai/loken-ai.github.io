A full-Rust inference stack that runs language and generative-media models on your own machine. One server speaks the OpenAI, Ollama and Anthropic APIs and calls nothing out.

  • NVIDIA through CUDA
  • AMD through ROCm
  • Vulkan
  • Intel through OpenCL
  • The host processor
  • Several machines as one
